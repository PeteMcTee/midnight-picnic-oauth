# midnight-picnic-oauth

## Public URLs (GitHub Pages)

- Home: https://petemctee.github.io/midnight-picnic-oauth/
- Privacy: https://petemctee.github.io/midnight-picnic-oauth/privacy.html
- Terms: https://petemctee.github.io/midnight-picnic-oauth/terms.html

Authorized JavaScript origin / domain for the OAuth client: `petemctee.github.io`

Source files: `index.html`, `privacy.html`, `terms.html`. No tracking scripts, no secrets.
